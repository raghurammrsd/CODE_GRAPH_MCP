            get_context
            CORE
          

          
Compile a token-bounded, coverage-optimized ContextPacket containing verified symbols, compressed relationships, routes, DI providers, packages, and related tests. Preserves UNKNOWN, POSSIBLE, and AMBIGUOUS states explicitly. Does not return full raw files; use targeted get_file or read_file only if exact omitted lines are needed afterward.

            Evidence Classification

            AST_VERIFIED
            Python AST / Tree-sitter
            100% deterministic syntax fact. Symbol definitions, class inheritances, explicit calls, and module imports.
          

          

            STATIC_VERIFIED
            Dataflow / Symbol Resolution
            Statically verified caller-callee chains and type annotations without dynamic runtime guessing.

            Database table reads, mutations, ORM column mappings, and migration lineages.

            Execution Telemetry
            Reconciled dynamic call-traces observed during live test suite or server runs.
